# QuantX Plugin Roadmap

The plugin system exists conceptually from M0. Its ecosystem matures incrementally.

## Early plugins

- Paper broker
- First Indian broker adapter
- First market-data adapter
- Strategy examples
- Notification adapter

## Intermediate plugins

- Additional brokers
- OpenAlgo adapter
- Options analytics
- vectorized research accelerator
- optimization adapters
- external signal integrations

## Advanced plugins

- AI providers
- agent framework integrations
- advanced portfolio/risk plugins
- community-developed strategies
- additional data vendors

## Registry

The initial registry can be an index of versioned Git repositories/packages. A central marketplace is not required for the architecture.

## Compatibility

Plugin API compatibility, capability manifests and contract tests are required before treating the ecosystem as stable.
