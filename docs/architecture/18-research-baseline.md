# QuantX Research Baseline

The current architecture drafts are informed by:

- QuantumTrade v1.6 for existing event-driven trading, safety, execution and session/API work
- OpenAlgo for the Indian broker/API/control-plane product surface
- Hummingbot for modular connectors and extension patterns
- NautilusTrader for deterministic event-driven execution and adapter architecture
- Freqtrade and Jesse for strategy and research workflows
- LEAN for research-to-live continuity
- vectorbt for optional vectorized research acceleration

These are reference inputs, not implementation dependencies. QuantX should integrate or improve existing capabilities where appropriate and avoid copying projects wholesale.
