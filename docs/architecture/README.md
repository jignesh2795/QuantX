# QuantX Architecture

This directory will contain the architecture specification for QuantX.

The architecture is intentionally documented before production implementation so that the repository has one agreed direction rather than another parallel experimental implementation.

Planned documents include:

- overview
- architectural principles
- domain model
- event model
- execution model
- plugin architecture
- adapter architecture
- capability system
- strategy runtime and Strategy IR
- data architecture
- research architecture
- control plane
- security model
- deployment model
