# QuantX v0.1 Repository Tree — Historical Target

**Historical document:** this records the smaller repository shape proposed at the start of v0.1. It is retained for architectural history and is **not** the authoritative description of the current source tree.

For the current implementation tree, see `docs/architecture/41-current-package-map.md`.

## Deliberately excluded from v0.1

- Web frontend
- AI/agent runtime
- Multi-broker production matrix
- Advanced options analytics
- Cloud deployment
- Distributed message brokers
- SaaS/multi-tenant features
- Vectorized research engine integration

Those remain later capabilities/plugins unless a v0.1 dependency proves necessary.
